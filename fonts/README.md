Subset (printable ASCII plus UI punctuation, arrows, and star glyphs) WOFF builds of
Instrument Serif, Geist, and Geist Mono, embedded into the animated SVG cards by
`scripts/render_readme_cards.py`. Regenerate anytime with `python scripts/build_fonts.py`.
